# Treksor on Apple Watch

The watch opens to the latest published Power Thought, with its editorial date. It fetches the public dashboard feed directly and keeps a dated copy for offline reading. A second view shows three optional seven-day totals from the paired iPhone: finished gym sessions, recorded sets and timed practice minutes. Progress sharing is off by default. Enable it in **Progress → Your connected life**. The watch sends a read-only request each time the progress view opens. It clears the response when the app backgrounds, the view closes or the connection drops.

Power Thought alerts are a separate opt-in on iPhone. Apple routes notifications to the iPhone or the unlocked paired watch based on settings and device state. Treksor provides a native notification view using its original mark, system type and Architect palette. A signed iPhone and watch build with working APNs credentials is required for end-to-end delivery verification.
